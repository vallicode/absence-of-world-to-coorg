# Location-specific image sources

The main visual treatment now uses location-specific Wikimedia Commons photos loaded directly in the browser:

- Abbey Falls, Coorg — `Abbe falls.jpg`
- Balamuri, Coorg — `Areca Paddy Mist Balamuri Coorg Feb24 A7C 09428.jpg`
- MGR Chennai Central — `Chennai central view.jpg`

They are requested through Wikimedia Commons' `Special:FilePath` endpoint. This keeps the site focused on real Chennai and Coorg imagery while avoiding generic placeholder photography.
