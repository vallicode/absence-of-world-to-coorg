# Absence of World → Coorg

A premium, responsive luxury itinerary website for a three-day Coorg escape.

## Run

Open `index.html` in a modern browser. The project uses CDN-hosted Bootstrap 5, AOS, Font Awesome, Google Fonts, and Picsum placeholder photography, so an internet connection is needed for complete styling and imagery.

## Pages

- `index.html` — cinematic home page, roadmap, daily highlights, troop preview
- `day1.html`, `day2.html`, `day3.html` — itinerary timelines and animated route sections
- `gallery.html` — filterable Pinterest-style masonry gallery with lightbox
- `members.html` — eleven animated member cards

All presentational styling is in `css/`; interactions are in `js/`.
